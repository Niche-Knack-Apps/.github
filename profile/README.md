# Niche-Knack

**Smart Tools. Sharp Solutions.** — [nk.tools](https://nk.tools)

One engineer in Ohio, making apps for narrow needs. An app isn't done when it
works; it has to be a pleasure to use. Local files and useful tools come first.

## The apps

Every app is in beta. Request a place on its page at [nk.tools](https://nk.tools/apps).

| App | What it does | Platforms |
| --- | --- | --- |
| [Pocket Nerd](https://nk.tools/pocket-nerd) | A scratchpad for money. Write down what you spent in seconds and see what it does to tomorrow. Nothing is wired to a bank. | Android |
| [LedgerKeep](https://nk.tools/ledgerkeep) | Double-entry books in plain-text Ledger files, with Git history, bill reminders and budgets. | Android, Linux, Windows, macOS |
| [Clip Dr.](https://nk.tools/clip-dr) | Turn a long recording into useful clips: find the passage, make the edit, repair the sound. | Linux, Windows, Android recorder |
| [Rabbit Trail](https://nk.tools/rabbit-trail) | An evidence board and research archive that follows names, dates and relationships back to their sources. | Android, Linux, Windows |
| [Choirboy](https://nk.tools/choirboy) | Choose what gets filtered in media you own or legitimately access — Plex, Emby, Jellyfin and more. | Android, Linux, Roku |
| [Euphonics](https://nk.tools/euphonics) | Find the right rhyme, try a near rhyme, and give a few words room to grow. | Android |

## Open source

Some tools are free and open, right here:

- **[z9s](https://github.com/Niche-Knack-Apps/z9s)** — a k9s-style terminal UI for
  [Zarf](https://zarf.dev), the airgap-native package manager for Kubernetes. One
  static binary for Linux, macOS and Windows.
- **[nines](https://github.com/Niche-Knack-Apps/nines)** — the k9s-shaped terminal
  shell behind z9s, specified once and implemented in Go and Rust.
